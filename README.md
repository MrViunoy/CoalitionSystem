# Coalitions

Coalition tags for chat, the player list, and overhead names. The plugin has Russian and English builds.

## Build / Сборка

Requires Java 21 and Maven.

- Russian / Русская версия: `mvn clean package`
- English / Английская версия: `mvn clean package -Penglish`

The JARs are written to `target/`:

- `Coalitions-1.0.0-ru.jar`
- `Coalitions-1.0.0-en.jar`

Upload the appropriate JAR as a separate download on GitHub Releases or CurseForge.

Обычная сборка создаёт русский JAR, а профиль `english` — английский. Оба файла используют одинаковые команды и сохраняют данные коалиций в одном формате.
